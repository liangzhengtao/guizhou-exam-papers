## 一、无机化学反应方程式

### 1. 钠及其化合物

| 反应 | 化学方程式 | 备注 |
|------|----------|------|
| 钠与水 | $2Na + 2H_2O = 2NaOH + H_2\uparrow$ | 浮、熔、游、响、红 |
| 钠与氧气（常温） | $4Na + O_2 = 2Na_2O$ | 白色固体 |
| 钠与氧气（点燃） | $2Na + O_2 \xrightarrow{点燃} Na_2O_2$ | 淡黄色固体 |
| 氧化钠与水 | $Na_2O + H_2O = 2NaOH$ | |
| 过氧化钠与水 | $2Na_2O_2 + 2H_2O = 4NaOH + O_2\uparrow$ | 漂白、供氧 |
| 过氧化钠与CO₂ | $2Na_2O_2 + 2CO_2 = 2Na_2CO_3 + O_2$ | 呼吸面具供氧 |
| 碳酸钠与盐酸 | $Na_2CO_3 + 2HCl = 2NaCl + H_2O + CO_2\uparrow$ | |
| 碳酸氢钠与盐酸 | $NaHCO_3 + HCl = NaCl + H_2O + CO_2\uparrow$ | 比碳酸钠反应快 |
| 碳酸氢钠受热分解 | $2NaHCO_3 \xrightarrow{\Delta} Na_2CO_3 + H_2O + CO_2\uparrow$ | |
| 碳酸钠与碳酸氢钠转化 | $Na_2CO_3 + H_2O + CO_2 = 2NaHCO_3$ | |

**易错点：**
- $Na_2O_2$ 与水/ $CO_2$ 反应时，$Na_2O_2$ 既是氧化剂又是还原剂
- $Na_2O_2$ 中氧为 $-1$ 价

### 2. 铝及其化合物

| 反应 | 化学方程式 | 备注 |
|------|----------|------|
| 铝与盐酸 | $2Al + 6HCl = 2AlCl_3 + 3H_2\uparrow$ | |
| 铝与NaOH | $2Al + 2NaOH + 2H_2O = 2NaAlO_2 + 3H_2\uparrow$ | 铝的两性 |
| 氧化铝与盐酸 | $Al_2O_3 + 6HCl = 2AlCl_3 + 3H_2O$ | |
| 氧化铝与NaOH | $Al_2O_3 + 2NaOH = 2NaAlO_2 + H_2O$ | 两性氧化物 |
| 氢氧化铝与盐酸 | $Al(OH)_3 + 3HCl = AlCl_3 + 3H_2O$ | |
| 氢氧化铝与NaOH | $Al(OH)_3 + NaOH = NaAlO_2 + 2H_2O$ | 两性氢氧化物 |
| 制备氢氧化铝 | $AlCl_3 + 3NH_3 \cdot H_2O = Al(OH)_3\downarrow + 3NH_4Cl$ | 用氨水不用NaOH |
| 明矾净水原理 | $Al^{3+} + 3H_2O \rightleftharpoons Al(OH)_3(胶体) + 3H^+$ | 水解 |

**易错点：**
- $Al(OH)_3$ 只溶于强碱，不溶于弱碱（氨水）
- 明矾净水是利用 $Al^{3+}$ 水解生成胶体

### 3. 铁及其化合物

| 反应 | 化学方程式 | 备注 |
|------|----------|------|
| 铁与盐酸 | $Fe + 2HCl = FeCl_2 + H_2\uparrow$ | 生成 $Fe^{2+}$ |
| 铁与氯气 | $2Fe + 3Cl_2 \xrightarrow{点燃} 2FeCl_3$ | 生成 $Fe^{3+}$ |
| 铁与硫酸铜 | $Fe + CuSO_4 = FeSO_4 + Cu$ | 湿法炼铜 |
| 氯化亚铁与氯气 | $2FeCl_2 + Cl_2 = 2FeCl_3$ | $Fe^{2+} \to Fe^{3+}$ |
| 氯化铁与铁 | $2FeCl_3 + Fe = 3FeCl_2$ | $Fe^{3+} \to Fe^{2+}$ |
| 氯化铁与铜 | $2FeCl_3 + Cu = 2FeCl_2 + CuCl_2$ | 刻蚀铜板 |
| 氢氧化亚铁制备 | $FeCl_2 + 2NaOH = Fe(OH)_2\downarrow + 2NaCl$ | 白色沉淀→灰绿→红褐 |
| 氢氧化亚铁氧化 | $4Fe(OH)_2 + O_2 + 2H_2O = 4Fe(OH)_3$ | |
| 氢氧化铁受热分解 | $2Fe(OH)_3 \xrightarrow{\Delta} Fe_2O_3 + 3H_2O$ | |

**$Fe^{2+}$ 与 $Fe^{3+}$ 检验：**
- $Fe^{3+}$：加 $KSCN$ → 血红色
- $Fe^{2+}$：先加 $KSCN$（不变色），再加氯水（变红色）

### 4. 氯及其化合物

| 反应 | 化学方程式 | 备注 |
|------|----------|------|
| 实验室制氯气 | $MnO_2 + 4HCl(浓) \xrightarrow{\Delta} MnCl_2 + Cl_2\uparrow + 2H_2O$ | |
| 氯气与水 | $Cl_2 + H_2O \rightleftharpoons HCl + HClO$ | 可逆反应 |
| 氯气与NaOH | $Cl_2 + 2NaOH = NaCl + NaClO + H_2O$ | 制漂白液 |
| 氯气与石灰乳 | $2Cl_2 + 2Ca(OH)_2 = Ca(ClO)_2 + CaCl_2 + 2H_2O$ | 制漂白粉 |
| 次氯酸分解 | $2HClO \xrightarrow{光照} 2HCl + O_2\uparrow$ | 不稳定 |
| 氯气与铁 | $2Fe + 3Cl_2 \xrightarrow{点燃} 2FeCl_3$ | 棕色烟 |
| 氯气与钠 | $2Na + Cl_2 \xrightarrow{点燃} 2NaCl$ | 黄色火焰 |

### 5. 硫及其化合物

| 反应 | 化学方程式 | 备注 |
|------|----------|------|
| 硫与铁 | $Fe + S \xrightarrow{\Delta} FeS$ | |
| 硫与铜 | $2Cu + S \xrightarrow{\Delta} Cu_2S$ | |
| 二氧化硫与水 | $SO_2 + H_2O \rightleftharpoons H_2SO_3$ | 可逆 |
| 二氧化硫与NaOH | $SO_2 + 2NaOH = Na_2SO_3 + H_2O$ | |
| 二氧化硫漂白 | $SO_2$ + 品红 → 无色（加热恢复） | 可逆漂白 |
| 三氧化硫与水 | $SO_3 + H_2O = H_2SO_4$ | |
| 浓硫酸与铜 | $Cu + 2H_2SO_4(浓) \xrightarrow{\Delta} CuSO_4 + SO_2\uparrow + 2H_2O$ | 强氧化性 |
| 浓硫酸与碳 | $C + 2H_2SO_4(浓) \xrightarrow{\Delta} CO_2\uparrow + 2SO_2\uparrow + 2H_2O$ | |

**易错点：**
- $SO_2$ 的漂白是可逆的（与 $HClO$ 不同）
- 浓硫酸与金属反应不生成 $H_2$，生成 $SO_2$
- 稀硫酸没有氧化性（指 $S^{+6}$），浓硫酸有强氧化性

### 6. 氮及其化合物

| 反应 | 化学方程式 | 备注 |
|------|----------|------|
| 氮气与氧气 | $N_2 + O_2 \xrightarrow{放电} 2NO$ | |
| 一氧化氮与氧气 | $2NO + O_2 = 2NO_2$ | 无色→红棕色 |
| 二氧化氮与水 | $3NO_2 + H_2O = 2HNO_3 + NO$ | |
| 氨的催化氧化 | $4NH_3 + 5O_2 \xrightarrow{催化剂/\Delta} 4NO + 6H_2O$ | 工业制硝酸第一步 |
| 氨与水 | $NH_3 + H_2O \rightleftharpoons NH_3 \cdot H_2O \rightleftharpoons NH_4^+ + OH^-$ | |
| 氨与盐酸 | $NH_3 + HCl = NH_4Cl$ | 白烟 |
| 实验室制氨 | $2NH_4Cl + Ca(OH)_2 \xrightarrow{\Delta} CaCl_2 + 2NH_3\uparrow + 2H_2O$ | |
| 铵盐受热分解 | $NH_4Cl \xrightarrow{\Delta} NH_3\uparrow + HCl\uparrow$ | |
| 硝酸与铜（稀） | $3Cu + 8HNO_3(稀) = 3Cu(NO_3)_2 + 2NO\uparrow + 4H_2O$ | |
| 硝酸与铜（浓） | $Cu + 4HNO_3(浓) = Cu(NO_3)_2 + 2NO_2\uparrow + 2H_2O$ | |
| 硝酸见光分解 | $4HNO_3 \xrightarrow{光照} 4NO_2\uparrow + O_2\uparrow + 2H_2O$ | 棕色瓶保存 |

**易错点：**
- 稀硝酸与浓硝酸的还原产物不同（$NO$ vs $NO_2$）
- 硝酸与金属反应不生成 $H_2$（$HNO_3$ 的强氧化性）
- 王水 = 浓硝酸 + 浓盐酸（1:3），可溶解金和铂

### 7. 碳、硅及其化合物

| 反应 | 化学方程式 | 备注 |
|------|----------|------|
| 碳与氧化铜 | $C + 2CuO \xrightarrow{高温} 2Cu + CO_2\uparrow$ | |
| 一氧化碳与氧化铁 | $3CO + Fe_2O_3 \xrightarrow{高温} 2Fe + 3CO_2$ | 高炉炼铁 |
| 硅与NaOH | $Si + 2NaOH + H_2O = Na_2SiO_3 + 2H_2\uparrow$ | |
| 二氧化硅与NaOH | $SiO_2 + 2NaOH = Na_2SiO_3 + H_2O$ | 玻璃瓶不能装NaOH |
| 二氧化硅与HF | $SiO_2 + 4HF = SiF_4\uparrow + 2H_2O$ | HF腐蚀玻璃 |
| 制备水玻璃 | $SiO_2 + Na_2CO_3 \xrightarrow{高温} Na_2SiO_3 + CO_2\uparrow$ | |
| 硅酸钠与盐酸 | $Na_2SiO_3 + 2HCl = 2NaCl + H_2SiO_3\downarrow$ | |

## 二、有机化学反应方程式

### 1. 烃的反应

| 反应 | 化学方程式 | 类型 |
|------|----------|------|
| 甲烷与氯气 | $CH_4 + Cl_2 \xrightarrow{光照} CH_3Cl + HCl$ | 取代 |
| 乙烯加溴 | $CH_2=CH_2 + Br_2 \to CH_2BrCH_2Br$ | 加成 |
| 乙烯加水 | $CH_2=CH_2 + H_2O \xrightarrow{催化剂} CH_3CH_2OH$ | 加成 |
| 乙烯加聚 | $nCH_2=CH_2 \xrightarrow{催化剂} [-CH_2-CH_2-]_n$ | 加聚 |
| 苯与溴 | $C_6H_6 + Br_2 \xrightarrow{FeBr_3} C_6H_5Br + HBr$ | 取代 |
| 苯的硝化 | $C_6H_6 + HNO_3 \xrightarrow{浓H_2SO_4/\Delta} C_6H_5NO_2 + H_2O$ | 取代 |
| 苯与氢气 | $C_6H_6 + 3H_2 \xrightarrow{Ni/\Delta} C_6H_{12}$ | 加成 |
| 甲苯与高锰酸钾 | $C_6H_5CH_3 \xrightarrow{KMnO_4/H^+} C_6H_5COOH$ | 氧化 |

### 2. 醇的反应

| 反应 | 化学方程式 | 类型 |
|------|----------|------|
| 乙醇催化氧化 | $2CH_3CH_2OH + O_2 \xrightarrow{Cu/\Delta} 2CH_3CHO + 2H_2O$ | 氧化 |
| 乙醇与钠 | $2CH_3CH_2OH + 2Na \to 2CH_3CH_2ONa + H_2\uparrow$ | 取代 |
| 乙醇消去 | $CH_3CH_2OH \xrightarrow{浓H_2SO_4/170°C} CH_2=CH_2\uparrow + H_2O$ | 消去 |
| 乙醇分子间脱水 | $2CH_3CH_2OH \xrightarrow{浓H_2SO_4/140°C} CH_3CH_2OCH_2CH_3 + H_2O$ | 取代 |

### 3. 醛的反应

| 反应 | 化学方程式 | 类型 |
|------|----------|------|
| 乙醛银镜反应 | $CH_3CHO + 2Ag(NH_3)_2OH \xrightarrow{\Delta} CH_3COONH_4 + 2Ag\downarrow + 3NH_3 + H_2O$ | 氧化 |
| 乙醛与新制$Cu(OH)_2$ | $CH_3CHO + 2Cu(OH)_2 \xrightarrow{\Delta} CH_3COOH + Cu_2O\downarrow + 2H_2O$ | 氧化 |
| 乙醛加氢还原 | $CH_3CHO + H_2 \xrightarrow{Ni/\Delta} CH_3CH_2OH$ | 还原 |

### 4. 羧酸与酯的反应

| 反应 | 化学方程式 | 类型 |
|------|----------|------|
| 乙酸与乙醇酯化 | $CH_3COOH + C_2H_5OH \xrightarrow{浓H_2SO_4/\Delta} CH_3COOC_2H_5 + H_2O$ | 酯化 |
| 乙酸乙酯水解（酸性） | $CH_3COOC_2H_5 + H_2O \xrightarrow{稀H_2SO_4/\Delta} CH_3COOH + C_2H_5OH$ | 水解 |
| 乙酸乙酯水解（碱性） | $CH_3COOC_2H_5 + NaOH \xrightarrow{\Delta} CH_3COONa + C_2H_5OH$ | 皂化 |

### 5. 高分子反应

| 反应 | 化学方程式 | 类型 |
|------|----------|------|
| 乙烯加聚 | $nCH_2=CH_2 \to [-CH_2-CH_2-]_n$ | 加聚 |
| 氯乙烯加聚 | $nCH_2=CHCl \to [-CH_2-CHCl-]_n$ | 加聚 |
| 苯酚与甲醛缩聚 | $nC_6H_5OH + nHCHO \xrightarrow{催化剂} [-C_6H_3(OH)-CH_2-]_n + nH_2O$ | 缩聚 |
| 对苯二甲酸与乙二醇 | $nHOOC-C_6H_4-COOH + nHOCH_2CH_2OH \to [-OC-C_6H_4-COOCH_2CH_2O-]_n + 2nH_2O$ | 缩聚（PET） |

**易错点：**
- 酯化反应断键：酸脱 $-OH$，醇脱 $-H$
- 有机方程式用 "$\to$" 不用 "$=$"
- 加聚产物无小分子生成，缩聚有小分子（$H_2O$ 等）生成

## 三、离子方程式

### 书写规则
1. 强酸、强碱、可溶性盐 → 拆成离子
2. 弱酸、弱碱、难溶物、气体、水、氧化物 → 保留化学式
3. 检查：原子守恒 + 电荷守恒

### 常考离子方程式

| 反应 | 离子方程式 |
|------|----------|
| 盐酸与NaOH | $H^+ + OH^- = H_2O$ |
| 碳酸钠与盐酸 | $CO_3^{2-} + 2H^+ = H_2O + CO_2\uparrow$ |
| 碳酸氢钠与盐酸 | $HCO_3^- + H^+ = H_2O + CO_2\uparrow$ |
| 氯化铁与NaOH | $Fe^{3+} + 3OH^- = Fe(OH)_3\downarrow$ |
| 硫酸铜与BaCl₂ | $Ba^{2+} + SO_4^{2-} = BaSO_4\downarrow$ |
| 铝与NaOH | $2Al + 2OH^- + 2H_2O = 2AlO_2^- + 3H_2\uparrow$ |
| 铁与氯化铁 | $Fe + 2Fe^{3+} = 3Fe^{2+}$ |
| 氯气与水 | $Cl_2 + H_2O \rightleftharpoons H^+ + Cl^- + HClO$ |
| 铝离子与氨水 | $Al^{3+} + 3NH_3 \cdot H_2O = Al(OH)_3\downarrow + 3NH_4^+$ |
| 碳酸根水解 | $CO_3^{2-} + H_2O \rightleftharpoons HCO_3^- + OH^-$ |
| 铁离子水解 | $Fe^{3+} + 3H_2O \rightleftharpoons Fe(OH)_3 + 3H^+$ |

### 离子共存判断

**不能共存的组合：**

| 生成物 | 不能共存的离子对 |
|--------|----------------|
| 沉淀 | $Ba^{2+}$ 与 $SO_4^{2-}$；$Ag^+$ 与 $Cl^-$；$Ca^{2+}$ 与 $CO_3^{2-}$ |
| 气体 | $H^+$ 与 $CO_3^{2-}$；$H^+$ 与 $SO_3^{2-}$；$NH_4^+$ 与 $OH^-$（加热） |
| 弱电解质 | $H^+$ 与 $OH^-$；$H^+$ 与 $CH_3COO^-$；$NH_4^+$ 与 $OH^-$（不加热） |
| 氧化还原 | $Fe^{3+}$ 与 $I^-$；$MnO_4^-$ 与 $Fe^{2+}$；$NO_3^-$ 与 $Fe^{2+}$（酸性条件） |

## 四、热化学方程式

### 书写规则
1. 注明物质的聚集状态：$(s)$ 固态、$(l)$ 液态、$(g)$ 气态、$(aq)$ 水溶液
2. 注明 $\Delta H$（kJ/mol）：$\Delta H < 0$ 放热，$\Delta H > 0$ 吸热
3. 化学计量数可以是分数
4. $\Delta H$ 与化学计量数成正比

### 常见热化学方程式

| 反应 | 热化学方程式 | $\Delta H$ |
|------|------------|------------|
| 碳燃烧（完全） | $C(s) + O_2(g) = CO_2(g)$ | $\Delta H = -393.5\ kJ/mol$ |
| 氢气燃烧 | $H_2(g) + \frac{1}{2}O_2(g) = H_2O(l)$ | $\Delta H = -285.8\ kJ/mol$ |
| 甲烷燃烧 | $CH_4(g) + 2O_2(g) = CO_2(g) + 2H_2O(l)$ | $\Delta H = -890.3\ kJ/mol$ |
| 中和反应 | $H^+(aq) + OH^-(aq) = H_2O(l)$ | $\Delta H = -57.3\ kJ/mol$ |
| 碳酸钙分解 | $CaCO_3(s) = CaO(s) + CO_2(g)$ | $\Delta H = +178.2\ kJ/mol$ |
| 氮氢合成氨 | $N_2(g) + 3H_2(g) \rightleftharpoons 2NH_3(g)$ | $\Delta H = -92.4\ kJ/mol$ |

### 盖斯定律

**定律：** 化学反应的热效应只与反应的始态和终态有关，与途径无关。

**应用：** 通过已知反应的 $\Delta H$，组合计算未知反应的 $\Delta H$。

**示例：** 已知：
- ① $C(s) + O_2(g) = CO_2(g)$，$\Delta H_1 = -393.5\ kJ/mol$
- ② $CO(g) + \frac{1}{2}O_2(g) = CO_2(g)$，$\Delta H_2 = -283.0\ kJ/mol$

求：$C(s) + \frac{1}{2}O_2(g) = CO(g)$ 的 $\Delta H$

解：$\Delta H = \Delta H_1 - \Delta H_2 = -393.5 - (-283.0) = -110.5\ kJ/mol$

## 📌 方程式速记技巧

### 氧化还原反应
- **升失氧还**：化合价升高 → 失电子 → 被氧化 → 还原剂
- **降得还氧**：化合价降低 → 得电子 → 被还原 → 氧化剂

### 离子方程式
- **拆分口诀**：强酸强碱可溶盐拆，其余不拆
- **守恒检查**：原子守恒 + 电荷守恒

### 有机反应
- **取代反应**：有上有下（一个原子/基团上去，一个下来）
- **加成反应**：只上不下（加到双键/三键上）
- **消去反应**：只下不上（脱去小分子形成不饱和键）
