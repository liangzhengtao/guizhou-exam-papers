## 一、力学公式

### 1. 牛顿运动定律

| 公式 | 说明 | 示例 |
|------|------|------|
| $F = ma$ | 牛顿第二定律：合力 = 质量 × 加速度 | 10N 的力作用在 2kg 物体上，$a = 5m/s^2$ |
| $F_1 = -F_2$ | 牛顿第三定律：作用力与反作用力等大反向 | 人推墙的力 = 墙推人的力 |
| $\sum F = 0$ | 物体处于平衡状态（静止或匀速） | 书放在桌上，重力 = 支持力 |

### 2. 运动学公式（匀变速直线运动）

| 公式 | 说明 | 适用条件 |
|------|------|---------|
| $v = v_0 + at$ | 速度-时间关系 | 匀变速 |
| $x = v_0 t + \frac{1}{2}at^2$ | 位移-时间关系 | 匀变速 |
| $v^2 - v_0^2 = 2ax$ | 速度-位移关系（无时间） | 匀变速 |
| $\bar{v} = \frac{v_0 + v}{2}$ | 平均速度 | 匀变速 |
| $\Delta x = aT^2$ | 连续相等时间内的位移差 | 匀变速 |

**示例：** 汽车以 $10m/s$ 的速度行驶，刹车加速度 $a = -2m/s^2$，求刹车后 3s 内的位移。

解：刹车时间 $t = \frac{v_0}{|a|} = 5s > 3s$，所以 $x = 10 \times 3 + \frac{1}{2} \times (-2) \times 9 = 21m$

### 3. 重力与摩擦力

| 公式 | 说明 | 示例 |
|------|------|------|
| $G = mg$ | 重力（$g ≈ 9.8m/s^2$） | 50kg 的人，$G = 490N$ |
| $f = \mu N$ | 滑动摩擦力（$N$ 为正压力） | $\mu = 0.3$，$N = 100N$，$f = 30N$ |
| $f_0 \leq \mu_0 N$ | 最大静摩擦力 | 静摩擦力根据平衡条件求解 |

### 4. 功和能

| 公式 | 说明 | 示例 |
|------|------|------|
| $W = Fs\cos\theta$ | 恒力做功（$\theta$ 为力与位移夹角） | $F = 10N$，$s = 5m$，$\theta = 60°$，$W = 25J$ |
| $W = Pt$ | 功率 × 时间 | $P = 100W$，$t = 10s$，$W = 1000J$ |
| $P = \frac{W}{t} = Fv$ | 功率 | 汽车以 $20m/s$ 匀速，$F = 1000N$，$P = 20kW$ |
| $E_k = \frac{1}{2}mv^2$ | 动能 | $m = 2kg$，$v = 3m/s$，$E_k = 9J$ |
| $E_p = mgh$ | 重力势能（$h$ 为相对高度） | $m = 1kg$，$h = 10m$，$E_p = 100J$ |
| $E_p = \frac{1}{2}kx^2$ | 弹性势能 | $k = 200N/m$，$x = 0.1m$，$E_p = 1J$ |

**动能定理：**
$$W_{合} = \Delta E_k = \frac{1}{2}mv^2 - \frac{1}{2}mv_0^2$$

**示例：** 一个 2kg 的物体从静止开始，在 10N 的合力作用下移动 5m，求末速度。

解：$W_{合} = 10 \times 5 = 50J$，$\frac{1}{2} \times 2 \times v^2 = 50$，$v = \sqrt{50} ≈ 7.07m/s$

**机械能守恒：**
$$E_{k1} + E_{p1} = E_{k2} + E_{p2}$$

条件：只有重力或弹力做功

### 5. 动量

| 公式 | 说明 | 示例 |
|------|------|------|
| $p = mv$ | 动量 | $m = 2kg$，$v = 3m/s$，$p = 6\ kg \cdot m/s$ |
| $I = Ft$ | 冲量 | $F = 10N$，$t = 2s$，$I = 20\ N \cdot s$ |
| $I = \Delta p$ | 动量定理：冲量 = 动量变化 | |

**动量守恒定律：**
$$m_1 v_1 + m_2 v_2 = m_1 v_1' + m_2 v_2'$$

条件：系统所受合外力为零

**示例：** 质量 2kg 的球以 3m/s 撞击静止的 1kg 球，弹性碰撞后各自速度？

解：动量守恒：$2 \times 3 = 2v_1' + 1 \times v_2'$

动能守恒：$\frac{1}{2} \times 2 \times 9 = \frac{1}{2} \times 2 v_1'^2 + \frac{1}{2} \times 1 \times v_2'^2$

解得：$v_1' = 1m/s$，$v_2' = 4m/s$

### 6. 圆周运动

| 公式 | 说明 | 示例 |
|------|------|------|
| $v = \omega r$ | 线速度与角速度 | $r = 2m$，$\omega = 3rad/s$，$v = 6m/s$ |
| $\omega = \frac{2\pi}{T} = 2\pi f$ | 角速度与周期/频率 | $T = 2s$，$\omega = \pi\ rad/s$ |
| $a_c = \frac{v^2}{r} = \omega^2 r$ | 向心加速度 | $v = 4m/s$，$r = 2m$，$a_c = 8m/s^2$ |
| $F_c = m\frac{v^2}{r} = m\omega^2 r$ | 向心力 | |

### 7. 万有引力

| 公式 | 说明 | 示例 |
|------|------|------|
| $F = G\frac{Mm}{r^2}$ | 万有引力定律（$G = 6.67 \times 10^{-11}$） | |
| $g = \frac{GM}{R^2}$ | 地球表面重力加速度 | |
| $v = \sqrt{\frac{GM}{r}}$ | 卫星环绕速度 | 近地卫星：$v ≈ 7.9km/s$ |
| $T = 2\pi\sqrt{\frac{r^3}{GM}}$ | 卫星周期 | 同步卫星：$T = 24h$ |

**示例：** 求地球的第一宇宙速度。

解：$v = \sqrt{gR} = \sqrt{9.8 \times 6.4 \times 10^6} ≈ 7.9 \times 10^3 m/s = 7.9km/s$

## 二、电磁学公式

### 1. 库仑定律与电场

| 公式 | 说明 | 示例 |
|------|------|------|
| $F = k\frac{q_1 q_2}{r^2}$ | 库仑定律（$k = 9 \times 10^9$） | $q_1 = q_2 = 10^{-6}C$，$r = 0.1m$，$F = 0.9N$ |
| $E = \frac{F}{q}$ | 电场强度定义 | $F = 0.1N$，$q = 10^{-4}C$，$E = 1000N/C$ |
| $E = k\frac{Q}{r^2}$ | 点电荷电场强度 | |
| $E = \frac{U}{d}$ | 匀强电场（$d$ 为沿场强方向距离） | |
| $U = \frac{W}{q}$ | 电势差 | $W = 10^{-3}J$，$q = 10^{-5}C$，$U = 100V$ |
| $W = qU$ | 电场力做功 | |
| $C = \frac{Q}{U} = \frac{\varepsilon S}{4\pi kd}$ | 平行板电容器 | |

### 2. 恒定电流

| 公式 | 说明 | 示例 |
|------|------|------|
| $I = \frac{Q}{t}$ | 电流定义 | $Q = 5C$，$t = 10s$，$I = 0.5A$ |
| $R = \rho\frac{L}{S}$ | 电阻定律（$\rho$ 为电阻率） | 铜线加长一倍，电阻加倍 |
| $U = IR$ | 欧姆定律 | $I = 2A$，$R = 5\Omega$，$U = 10V$ |
| $P = UI = I^2R = \frac{U^2}{R}$ | 电功率 | |
| $W = UIt = I^2Rt = \frac{U^2}{R}t$ | 电功（纯电阻电路） | |
| $Q = I^2Rt$ | 焦耳定律 | |

**闭合电路欧姆定律：**
$$I = \frac{E}{R + r}$$

其中 $E$ 为电动势，$r$ 为内阻，$R$ 为外电阻

**示例：** 电源 $E = 12V$，$r = 1\Omega$，外电阻 $R = 5\Omega$，求电流和路端电压。

解：$I = \frac{12}{5+1} = 2A$，$U = IR = 2 \times 5 = 10V$

### 3. 磁场

| 公式 | 说明 | 示例 |
|------|------|------|
| $F = BIL$ | 安培力（$B \perp I$） | $B = 0.5T$，$I = 2A$，$L = 0.3m$，$F = 0.3N$ |
| $F = qvB$ | 洛伦兹力（$B \perp v$） | $q = 10^{-6}C$，$v = 10^3m/s$，$B = 0.1T$，$F = 10^{-4}N$ |
| $r = \frac{mv}{qB}$ | 带电粒子在磁场中圆周运动半径 | |
| $T = \frac{2\pi m}{qB}$ | 带电粒子在磁场中圆周运动周期 | 周期与速度无关 |

### 4. 电磁感应

| 公式 | 说明 | 示例 |
|------|------|------|
| $\varepsilon = n\frac{\Delta\Phi}{\Delta t}$ | 法拉第电磁感应定律 | $n = 100$，$\Delta\Phi = 0.02Wb$，$\Delta t = 0.1s$，$\varepsilon = 20V$ |
| $\varepsilon = BLv$ | 导体棒切割磁感线（$B \perp v$） | $B = 0.5T$，$L = 0.4m$，$v = 3m/s$，$\varepsilon = 0.6V$ |
| $\Phi = BS$ | 磁通量（$B \perp S$） | $B = 0.2T$，$S = 0.5m^2$，$\Phi = 0.1Wb$ |
| $L = \frac{\Phi}{I}$ | 自感系数 | |

**楞次定律：** 感应电流的方向总是阻碍引起感应电流的磁通量的变化

## 三、热学公式

| 公式 | 说明 | 示例 |
|------|------|------|
| $\frac{pV}{T} = C$ | 理想气体状态方程（$T$ 用热力学温度） | |
| $pV = nRT$ | 理想气体状态方程（另一形式） | $n$ 为物质的量，$R = 8.314 J/(mol \cdot K)$ |
| $\Delta U = W + Q$ | 热力学第一定律 | $\Delta U$：内能变化，$W$：做功，$Q$：热量 |
| $Q = cm\Delta T$ | 热量计算 | $c$ 为比热容，$m$ 为质量 |
| $Q = \lambda m$ | 熔化热 | $\lambda$ 为熔化热 |
| $Q = Lm$ | 汽化热 | $L$ 为汽化热 |

**符号规定：**
- $Q > 0$：吸热；$Q < 0$：放热
- $W > 0$：外界对气体做功；$W < 0$：气体对外做功
- $\Delta U > 0$：内能增加；$\Delta U < 0$：内能减小

**示例：** 一定量气体从外界吸热 500J，同时对外做功 200J，求内能变化。

解：$Q = +500J$，$W = -200J$（对外做功为负），$\Delta U = 500 + (-200) = 300J$（内能增加）

## 四、光学公式

### 1. 几何光学

| 公式 | 说明 | 示例 |
|------|------|------|
| $n_1 \sin\theta_1 = n_2 \sin\theta_2$ | 折射定律（斯涅尔定律） | $n_1 = 1$，$n_2 = 1.5$，$\theta_1 = 30°$ |
| $\sin C = \frac{1}{n}$ | 全反射临界角 | $n = 1.5$，$C = \arcsin\frac{2}{3} ≈ 41.8°$ |
| $n = \frac{c}{v}$ | 折射率（$c$ 为光速，$v$ 为介质中光速） | |

**示例：** 光从玻璃（$n = 1.5$）射入空气，求发生全反射的临界角。

解：$\sin C = \frac{1}{n} = \frac{1}{1.5} = \frac{2}{3}$，$C = \arcsin\frac{2}{3} ≈ 41.8°$

### 2. 物理光学

| 公式 | 说明 | 示例 |
|------|------|------|
| $E = h\nu$ | 光子能量（$h = 6.63 \times 10^{-34}J \cdot s$） | $\nu = 5 \times 10^{14}Hz$，$E = 3.3 \times 10^{-19}J$ |
| $E_k = h\nu - W_0$ | 光电效应方程 | $W_0$ 为逸出功 |
| $\lambda = \frac{h}{p} = \frac{h}{mv}$ | 德布罗意波（物质波） | |
| $\Delta x = \frac{L}{d}\lambda$ | 双缝干涉条纹间距 | $L$ 为屏距，$d$ 为缝距 |

## 五、原子物理公式

| 公式 | 说明 | 示例 |
|------|------|------|
| $E = mc^2$ | 质能方程 | $c = 3 \times 10^8 m/s$ |
| $\Delta E = \Delta m \cdot c^2$ | 核反应中的能量释放 | |
| $h\nu = E_m - E_n$ | 能级跃迁（$m > n$ 发射光子） | |
| $E_n = \frac{E_1}{n^2}$ | 氢原子能级（$E_1 = -13.6eV$） | $n=2$：$E_2 = -3.4eV$ |
| $N = N_0(\frac{1}{2})^{t/T}$ | 半衰期公式 | $T$ 为半衰期 |

**示例：** 氢原子从 $n=3$ 跃迁到 $n=2$，求发射光子的频率。

解：$E_3 = \frac{-13.6}{9} = -1.51eV$，$E_2 = \frac{-13.6}{4} = -3.4eV$

$\Delta E = E_3 - E_2 = -1.51 - (-3.4) = 1.89eV = 1.89 \times 1.6 \times 10^{-19}J$

$\nu = \frac{\Delta E}{h} = \frac{3.02 \times 10^{-19}}{6.63 \times 10^{-34}} ≈ 4.56 \times 10^{14}Hz$

## 📌 公式速记口诀

### 力学口诀
- **牛二律：** 合力等于质量乘加速度
- **动能定理：** 合力做功等于动能变化量
- **动量守恒：** 系统合外力为零，总动量不变

### 电磁学口诀
- **库仑定律：** 电荷之间力，距离平方反比
- **欧姆定律：** 电压等于电流乘电阻
- **法拉第定律：** 感应电动势等于磁通量变化率乘匝数

### 热学口诀
- **气态方程：** 压强乘体积除以温度等于常数
- **热一律：** 内能变化等于吸热加上做功

### 光学口诀
- **折射定律：** 入射角正弦乘折射率等于折射角正弦乘折射率
- **光电效应：** 光子能量等于逸出功加最大初动能
