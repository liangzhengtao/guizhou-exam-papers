## 一、函数公式

### 1. 基本初等函数

| 函数 | 公式 | 定义域 | 值域 | 图像特征 |
|------|------|--------|------|---------|
| 一次函数 | $y = kx + b$ | $\mathbb{R}$ | $\mathbb{R}$ | 直线，$k > 0$ 递增 |
| 二次函数 | $y = ax^2 + bx + c$ | $\mathbb{R}$ | $[\frac{4ac-b^2}{4a}, +\infty)$（$a>0$） | 抛物线 |
| 指数函数 | $y = a^x$（$a > 0, a \neq 1$） | $\mathbb{R}$ | $(0, +\infty)$ | 过 $(0,1)$，$a > 1$ 递增 |
| 对数函数 | $y = \log_a x$（$a > 0, a \neq 1$） | $(0, +\infty)$ | $\mathbb{R}$ | 过 $(1,0)$，$a > 1$ 递增 |
| 幂函数 | $y = x^a$ | 视 $a$ 而定 | 视 $a$ 而定 | 过 $(1,1)$ |

### 2. 二次函数核心公式

| 公式 | 说明 |
|------|------|
| $x = -\frac{b}{2a}$ | 对称轴 |
| $\frac{4ac - b^2}{4a}$ | 顶点纵坐标（最值） |
| $\Delta = b^2 - 4ac$ | 判别式 |
| $x_{1,2} = \frac{-b \pm \sqrt{\Delta}}{2a}$ | 求根公式 |
| $x_1 + x_2 = -\frac{b}{a}$，$x_1 x_2 = \frac{c}{a}$ | 韦达定理 |

**示例：** $y = x^2 - 4x + 3$ 的对称轴和顶点。

解：对称轴 $x = -\frac{-4}{2} = 2$，$y_{min} = \frac{4 \times 1 \times 3 - 16}{4} = -1$，顶点 $(2, -1)$

### 3. 指数与对数运算

**指数运算律：**
- $a^m \cdot a^n = a^{m+n}$
- $(a^m)^n = a^{mn}$
- $(ab)^n = a^n b^n$
- $a^{-n} = \frac{1}{a^n}$
- $a^{\frac{m}{n}} = \sqrt[n]{a^m}$

**对数运算律：**
- $\log_a(MN) = \log_a M + \log_a N$
- $\log_a\frac{M}{N} = \log_a M - \log_a N$
- $\log_a M^n = n\log_a M$
- $\log_a a = 1$，$\log_a 1 = 0$
- $a^{\log_a N} = N$

**换底公式：**
$$\log_a b = \frac{\log_c b}{\log_c a} = \frac{\ln b}{\ln a}$$

**推论：**
- $\log_a b \cdot \log_b a = 1$
- $\log_a b \cdot \log_b c = \log_a c$

## 二、三角函数公式

### 1. 基本关系

$$\sin^2\alpha + \cos^2\alpha = 1$$

$$\tan\alpha = \frac{\sin\alpha}{\cos\alpha}$$

$$1 + \tan^2\alpha = \frac{1}{\cos^2\alpha} = \sec^2\alpha$$

### 2. 诱导公式

**口诀：奇变偶不变，符号看象限**

| 公式 | 结果 |
|------|------|
| $\sin(\pi - \alpha)$ | $\sin\alpha$ |
| $\sin(\pi + \alpha)$ | $-\sin\alpha$ |
| $\cos(\pi - \alpha)$ | $-\cos\alpha$ |
| $\cos(\pi + \alpha)$ | $-\cos\alpha$ |
| $\sin(\frac{\pi}{2} - \alpha)$ | $\cos\alpha$ |
| $\sin(\frac{\pi}{2} + \alpha)$ | $\cos\alpha$ |
| $\cos(\frac{\pi}{2} - \alpha)$ | $\sin\alpha$ |
| $\cos(\frac{\pi}{2} + \alpha)$ | $-\sin\alpha$ |

### 3. 和差公式

$$\sin(\alpha \pm \beta) = \sin\alpha\cos\beta \pm \cos\alpha\sin\beta$$

$$\cos(\alpha \pm \beta) = \cos\alpha\cos\beta \mp \sin\alpha\sin\beta$$

$$\tan(\alpha \pm \beta) = \frac{\tan\alpha \pm \tan\beta}{1 \mp \tan\alpha\tan\beta}$$

**示例：** $\sin 75° = \sin(45° + 30°) = \sin 45°\cos 30° + \cos 45°\sin 30° = \frac{\sqrt{6} + \sqrt{2}}{4}$

### 4. 二倍角公式

$$\sin 2\alpha = 2\sin\alpha\cos\alpha$$

$$\cos 2\alpha = \cos^2\alpha - \sin^2\alpha = 2\cos^2\alpha - 1 = 1 - 2\sin^2\alpha$$

$$\tan 2\alpha = \frac{2\tan\alpha}{1 - \tan^2\alpha}$$

### 5. 半角公式

$$\sin\frac{\alpha}{2} = \pm\sqrt{\frac{1-\cos\alpha}{2}}$$

$$\cos\frac{\alpha}{2} = \pm\sqrt{\frac{1+\cos\alpha}{2}}$$

$$\tan\frac{\alpha}{2} = \frac{\sin\alpha}{1+\cos\alpha} = \frac{1-\cos\alpha}{\sin\alpha}$$

### 6. 辅助角公式

$$a\sin\alpha + b\cos\alpha = \sqrt{a^2 + b^2}\sin(\alpha + \varphi)$$

其中 $\tan\varphi = \frac{b}{a}$

**示例：** $\sin x + \sqrt{3}\cos x = 2\sin(x + \frac{\pi}{3})$

### 7. 和差化积

$$\sin A + \sin B = 2\sin\frac{A+B}{2}\cos\frac{A-B}{2}$$

$$\sin A - \sin B = 2\cos\frac{A+B}{2}\sin\frac{A-B}{2}$$

$$\cos A + \cos B = 2\cos\frac{A+B}{2}\cos\frac{A-B}{2}$$

$$\cos A - \cos B = -2\sin\frac{A+B}{2}\sin\frac{A-B}{2}$$

### 8. 正弦定理与余弦定理

**正弦定理：**
$$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$$

**余弦定理：**
$$c^2 = a^2 + b^2 - 2ab\cos C$$

**三角形面积：**
$$S = \frac{1}{2}ab\sin C = \frac{1}{2}bc\sin A = \frac{1}{2}ac\sin B$$

**示例：** $\triangle ABC$ 中，$a = 3$，$b = 5$，$C = 60°$，求 $c$ 和 $S$。

解：$c^2 = 9 + 25 - 2 \times 3 \times 5 \times \frac{1}{2} = 19$，$c = \sqrt{19}$

$S = \frac{1}{2} \times 3 \times 5 \times \sin 60° = \frac{15\sqrt{3}}{4}$

## 三、数列公式

### 1. 等差数列

| 公式 | 说明 |
|------|------|
| $a_n = a_1 + (n-1)d$ | 通项公式 |
| $S_n = \frac{n(a_1 + a_n)}{2} = na_1 + \frac{n(n-1)}{2}d$ | 前 $n$ 项和 |
| $a_n = \frac{a_{n-1} + a_{n+1}}{2}$ | 等差中项 |
| $S_n = \frac{d}{2}n^2 + (a_1 - \frac{d}{2})n$ | 二次函数形式（$d \neq 0$） |

**性质：**
- 若 $m + n = p + q$，则 $a_m + a_n = a_p + a_q$
- $S_n$，$S_{2n} - S_n$，$S_{3n} - S_{2n}$ 也成等差数列

**示例：** 等差数列中 $a_3 = 7$，$a_7 = 19$，求 $a_1$ 和 $d$。

解：$a_7 - a_3 = 4d = 12$，$d = 3$，$a_1 = a_3 - 2d = 7 - 6 = 1$

### 2. 等比数列

| 公式 | 说明 |
|------|------|
| $a_n = a_1 \cdot q^{n-1}$ | 通项公式（$q \neq 0$） |
| $S_n = \frac{a_1(1-q^n)}{1-q}$（$q \neq 1$） | 前 $n$ 项和 |
| $S_n = na_1$（$q = 1$） | 前 $n$ 项和 |
| $a_n^2 = a_{n-1} \cdot a_{n+1}$ | 等比中项 |

**性质：**
- 若 $m + n = p + q$，则 $a_m \cdot a_n = a_p \cdot a_q$
- $S_n$，$S_{2n} - S_n$，$S_{3n} - S_{2n}$ 也成等比数列（公比为 $q^n$）

**示例：** 等比数列中 $a_1 = 2$，$q = 3$，求 $a_5$ 和 $S_5$。

解：$a_5 = 2 \times 3^4 = 162$，$S_5 = \frac{2(1-3^5)}{1-3} = \frac{2 \times (-242)}{-2} = 242$

### 3. 常用求和方法

**裂项相消法：**
$$\frac{1}{n(n+1)} = \frac{1}{n} - \frac{1}{n+1}$$

$$\frac{1}{n(n+2)} = \frac{1}{2}(\frac{1}{n} - \frac{1}{n+2})$$

**错位相减法：** 适用于 $\{a_n \cdot b_n\}$，其中 $\{a_n\}$ 为等差，$\{b_n\}$ 为等比

**公式法：**
- $\sum_{k=1}^{n} k = \frac{n(n+1)}{2}$
- $\sum_{k=1}^{n} k^2 = \frac{n(n+1)(2n+1)}{6}$
- $\sum_{k=1}^{n} k^3 = [\frac{n(n+1)}{2}]^2$

## 四、导数公式

### 1. 基本导数公式

| 原函数 $f(x)$ | 导函数 $f'(x)$ |
|---------------|----------------|
| $C$（常数） | $0$ |
| $x^n$ | $nx^{n-1}$ |
| $\sin x$ | $\cos x$ |
| $\cos x$ | $-\sin x$ |
| $\tan x$ | $\sec^2 x = \frac{1}{\cos^2 x}$ |
| $e^x$ | $e^x$ |
| $a^x$ | $a^x \ln a$ |
| $\ln x$ | $\frac{1}{x}$ |
| $\log_a x$ | $\frac{1}{x\ln a}$ |

### 2. 导数运算法则

| 法则 | 公式 |
|------|------|
| 和差 | $[f(x) \pm g(x)]' = f'(x) \pm g'(x)$ |
| 积 | $[f(x) \cdot g(x)]' = f'(x)g(x) + f(x)g'(x)$ |
| 商 | $[\frac{f(x)}{g(x)}]' = \frac{f'(x)g(x) - f(x)g'(x)}{[g(x)]^2}$ |
| 复合 | $[f(g(x))]' = f'(g(x)) \cdot g'(x)$（链式法则） |

### 3. 常用求导示例

| 函数 | 导数 |
|------|------|
| $y = (2x+1)^3$ | $y' = 3(2x+1)^2 \cdot 2 = 6(2x+1)^2$ |
| $y = e^{2x}$ | $y' = e^{2x} \cdot 2 = 2e^{2x}$ |
| $y = \ln(x^2+1)$ | $y' = \frac{2x}{x^2+1}$ |
| $y = x \cdot e^x$ | $y' = e^x + xe^x = (1+x)e^x$ |
| $y = \frac{\sin x}{x}$ | $y' = \frac{x\cos x - \sin x}{x^2}$ |

### 4. 导数应用公式

**切线方程：** 曲线 $y = f(x)$ 在点 $(x_0, f(x_0))$ 处的切线方程为：
$$y - f(x_0) = f'(x_0)(x - x_0)$$

**单调性判断：**
- $f'(x) > 0$ → $f(x)$ 递增
- $f'(x) < 0$ → $f(x)$ 递减

**极值判断：**
- $f'(x_0) = 0$ 且 $f'(x)$ 在 $x_0$ 左右变号 → $x_0$ 为极值点

## 五、解析几何公式

### 1. 直线

| 公式 | 说明 |
|------|------|
| $y - y_1 = k(x - x_1)$ | 点斜式 |
| $y = kx + b$ | 斜截式 |
| $\frac{x}{a} + \frac{y}{b} = 1$ | 截距式 |
| $Ax + By + C = 0$ | 一般式 |
| $k = \frac{y_2 - y_1}{x_2 - x_1}$ | 斜率公式 |
| $k = \tan\alpha$ | 斜率与倾斜角 |

**两直线关系：**
- 平行：$k_1 = k_2$（且不重合）
- 垂直：$k_1 k_2 = -1$
- 夹角：$\tan\theta = |\frac{k_1 - k_2}{1 + k_1 k_2}|$

**点到直线距离：**
$$d = \frac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}$$

**示例：** 点 $(1, 2)$ 到直线 $3x + 4y - 5 = 0$ 的距离。

解：$d = \frac{|3 + 8 - 5|}{\sqrt{9 + 16}} = \frac{6}{5} = 1.2$

### 2. 圆

| 方程 | 形式 |
|------|------|
| 标准方程 | $(x-a)^2 + (y-b)^2 = r^2$，圆心 $(a,b)$，半径 $r$ |
| 一般方程 | $x^2 + y^2 + Dx + Ey + F = 0$，圆心 $(-\frac{D}{2}, -\frac{E}{2})$，$r = \frac{\sqrt{D^2+E^2-4F}}{2}$ |

**直线与圆的关系：**
- 相离：$d > r$
- 相切：$d = r$
- 相交：$d < r$，弦长 $= 2\sqrt{r^2 - d^2}$

### 3. 椭圆

| 项目 | 焦点在 $x$ 轴 | 焦点在 $y$ 轴 |
|------|--------------|--------------|
| 标准方程 | $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$（$a > b > 0$） | $\frac{x^2}{b^2} + \frac{y^2}{a^2} = 1$（$a > b > 0$） |
| 关系 | $c^2 = a^2 - b^2$ | $c^2 = a^2 - b^2$ |
| 顶点 | $(\pm a, 0)$，$(0, \pm b)$ | $(0, \pm a)$，$(\pm b, 0)$ |
| 焦点 | $(\pm c, 0)$ | $(0, \pm c)$ |
| 离心率 | $e = \frac{c}{a}$（$0 < e < 1$） | $e = \frac{c}{a}$（$0 < e < 1$） |
| 通径 | $\frac{2b^2}{a}$ | $\frac{2b^2}{a}$ |

**焦点三角形面积：** $S = b^2 \tan\frac{\theta}{2}$（$\theta$ 为 $\angle F_1PF_2$）

### 4. 双曲线

| 项目 | 焦点在 $x$ 轴 | 焦点在 $y$ 轴 |
|------|--------------|--------------|
| 标准方程 | $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$ | $\frac{y^2}{a^2} - \frac{x^2}{b^2} = 1$ |
| 关系 | $c^2 = a^2 + b^2$ | $c^2 = a^2 + b^2$ |
| 渐近线 | $y = \pm\frac{b}{a}x$ | $y = \pm\frac{a}{b}x$ |
| 离心率 | $e = \frac{c}{a}$（$e > 1$） | $e = \frac{c}{a}$（$e > 1$） |

### 5. 抛物线

| 方程 | 焦点 | 准线 |
|------|------|------|
| $y^2 = 2px$（$p > 0$） | $(\frac{p}{2}, 0)$ | $x = -\frac{p}{2}$ |
| $y^2 = -2px$（$p > 0$） | $(-\frac{p}{2}, 0)$ | $x = \frac{p}{2}$ |
| $x^2 = 2py$（$p > 0$） | $(0, \frac{p}{2})$ | $y = -\frac{p}{2}$ |
| $x^2 = -2py$（$p > 0$） | $(0, -\frac{p}{2})$ | $y = \frac{p}{2}$ |

**焦点弦长公式：** 过焦点的弦 $|AB| = x_1 + x_2 + p$

**示例：** 抛物线 $y^2 = 8x$ 的焦点和准线。

解：$2p = 8$，$p = 4$，焦点 $(2, 0)$，准线 $x = -2$

## 六、概率与统计公式

### 1. 排列组合

| 公式 | 说明 |
|------|------|
| $A_n^m = \frac{n!}{(n-m)!}$ | 排列（有序） |
| $C_n^m = \frac{n!}{m!(n-m)!}$ | 组合（无序） |
| $C_n^m = C_n^{n-m}$ | 组合对称性 |
| $C_n^m = C_{n-1}^{m-1} + C_{n-1}^m$ | 杨辉三角递推 |
| $C_n^0 + C_n^1 + \cdots + C_n^n = 2^n$ | 二项式系数和 |

**示例：** $C_{10}^3 = \frac{10!}{3!7!} = \frac{10 \times 9 \times 8}{3 \times 2 \times 1} = 120$

### 2. 二项式定理

$$(a+b)^n = \sum_{k=0}^{n} C_n^k a^{n-k} b^k$$

**通项：** $T_{r+1} = C_n^r a^{n-r} b^r$

**示例：** $(x+1)^5$ 的展开式中 $x^3$ 的系数。

解：$T_{r+1} = C_5^r x^{5-r}$，令 $5-r=3$，$r=2$，系数为 $C_5^2 = 10$

### 3. 概率公式

| 公式 | 说明 |
|------|------|
| $P(A) = \frac{m}{n}$ | 古典概型（$m$ 为有利事件数，$n$ 为总事件数） |
| $P(A \cup B) = P(A) + P(B) - P(A \cap B)$ | 加法公式 |
| $P(A \cup B) = P(A) + P(B)$ | 互斥事件 |
| $P(\bar{A}) = 1 - P(A)$ | 对立事件 |
| $P(A \cap B) = P(A) \cdot P(B)$ | 独立事件 |
| $P(B|A) = \frac{P(AB)}{P(A)}$ | 条件概率 |

### 4. 随机变量

**离散型随机变量：**
- 期望：$E(X) = \sum x_i P(X = x_i)$
- 方差：$D(X) = E(X^2) - [E(X)]^2$
- 标准差：$\sigma = \sqrt{D(X)}$

**常用分布：**

| 分布 | 概率 | 期望 | 方差 |
|------|------|------|------|
| 两点分布 $X \sim B(1,p)$ | $P(X=1)=p$ | $p$ | $p(1-p)$ |
| 二项分布 $X \sim B(n,p)$ | $P(X=k)=C_n^k p^k (1-p)^{n-k}$ | $np$ | $np(1-p)$ |
| 超几何分布 | $P(X=k)=\frac{C_M^k C_{N-M}^{n-k}}{C_N^n}$ | $\frac{nM}{N}$ | $\frac{nM(N-M)(N-n)}{N^2(N-1)}$ |

**期望和方差性质：**
- $E(aX+b) = aE(X) + b$
- $D(aX+b) = a^2 D(X)$
- $E(X+Y) = E(X) + E(Y)$
- 若 $X, Y$ 独立：$D(X+Y) = D(X) + D(Y)$

### 5. 统计公式

| 公式 | 说明 |
|------|------|
| $\bar{x} = \frac{1}{n}\sum_{i=1}^n x_i$ | 样本均值 |
| $s^2 = \frac{1}{n}\sum_{i=1}^n (x_i - \bar{x})^2$ | 样本方差 |
| $\hat{b} = \frac{\sum(x_i - \bar{x})(y_i - \bar{y})}{\sum(x_i - \bar{x})^2}$ | 回归系数 |
| $\hat{a} = \bar{y} - \hat{b}\bar{x}$ | 回归截距 |
| $\hat{y} = \hat{b}x + \hat{a}$ | 线性回归方程 |

**独立性检验：**
$$K^2 = \frac{n(ad - bc)^2}{(a+b)(c+d)(a+c)(b+d)}$$

## 📌 公式速记口诀

### 函数
- 对数真数大于零，底数大于零且不等于一
- 指数函数过 $(0,1)$，对数函数过 $(1,0)$

### 三角
- 奇变偶不变，符号看象限（诱导公式）
- 二倍角：正弦双倍，余弦三种形式

### 数列
- 等差用中项，等比用积项
- 等差看公差，等比看公比

### 解析几何
- 椭圆 $a$ 大 $c$ 小，$c^2 = a^2 - b^2$
- 双曲线 $c$ 大 $a$ 小，$c^2 = a^2 + b^2$
- 抛物线只看 $p$
