# 🧪 高考化学备考指南

> 化学是理综中最容易提分的科目，知识点零散但有规律可循。掌握核心考点，你也能拿高分！

---

## 📋 核心考点总结

### 一、化学反应原理（约 25 分）

#### 1. 化学反应速率与化学平衡

**核心知识：**
- 速率表达式：$v = \frac{\Delta c}{\Delta t}$
- 平衡常数：$K = \frac{生成物浓度的幂之积}{反应物浓度的幂之积}$
- 勒夏特列原理：改变条件，平衡向减弱该改变的方向移动

**常见题型：**
- 平衡移动方向判断
- 平衡常数与转化率计算
- 等效平衡问题
- 图像分析题

**解题技巧：**
- 速率比较：统一到同一物质的速率
- 平衡移动：只看浓度、压强、温度的影响
- 图像题：看起点、拐点、终点、趋势

**易错点：**
- 催化剂不影响平衡位置，只影响达到平衡的时间
- 增大压强不一定会使平衡移动（等体积反应）
- 平衡常数只与温度有关

#### 2. 电化学

**核心知识：**
- 原电池：化学能→电能
- 电解池：电能→化学能
- 负极氧化，正极还原（原电池）
- 阳极氧化，阴极还原（电解池）

**常见题型：**
- 电极反应方程式书写
- 正负极/阴阳极判断
- 电子/离子流向
- 电解产物判断
- 金属腐蚀与防护

**解题技巧：**
- 原电池：活泼金属为负极
- 电解池：阳极看材料（活性电极溶解，惰性电极看阴离子放电顺序）
- 放电顺序（阳极）：$S^{2-} > I^- > Br^- > Cl^- > OH^-$
- 放电顺序（阴极）：$Ag^+ > Cu^{2+} > H^+ > ...$

**易错点：**
- 盐桥中离子的移动方向
- 电解时溶液pH的变化
- 电镀时阳极材料的选择

#### 3. 溶液中的离子平衡

**核心知识：**
- 弱电解质的电离平衡
- 水的电离与pH
- 盐类水解
- 沉淀溶解平衡

**常见题型：**
- 溶液酸碱性判断
- 离子浓度大小比较
- 缓冲溶液问题
- $K_{sp}$ 计算

**解题技巧：**
- 离子浓度比较三守恒：电荷守恒、物料守恒、质子守恒
- 盐类水解口诀：有弱才水解，谁弱谁水解，谁强显谁性
- 混合溶液先判断反应，再分析剩余

### 二、有机化学（约 15 分）

#### 核心知识

**官能团与性质：**

| 官能团 | 名称 | 主要反应 |
|--------|------|---------|
| $-OH$ | 羟基 | 取代、消去、酯化、氧化 |
| $-CHO$ | 醛基 | 加成、氧化（银镜反应、与新制$Cu(OH)_2$） |
| $-COOH$ | 羧基 | 酸性、酯化 |
| $-COO-$ | 酯基 | 水解 |
| $C=C$ | 碳碳双键 | 加成、加聚、氧化 |
| $-X$ | 卤素原子 | 取代、消去 |
| $-NH_2$ | 氨基 | 碱性、缩合 |

**常见反应类型：**
- 取代反应：烷烃卤代、苯的硝化、酯化反应
- 加成反应：烯烃加氢、加卤素、加水
- 消去反应：醇→烯、卤代烃→烯
- 氧化反应：醇→醛→酸
- 还原反应：醛→醇
- 缩聚反应：氨基酸→蛋白质
- 加聚反应：单体→高分子

#### 解题模板

**有机推断题：**
1. 从分子式计算不饱和度
2. 根据反应条件和产物推断官能团
3. 写出结构简式
4. 完成化学方程式

**同分异构体书写：**
1. 先写碳链异构（主链由长到短）
2. 再写位置异构（官能团位置变化）
3. 最后写类别异构（官能团种类变化）

#### 常见有机化学方程式

**乙醇催化氧化：**
$$2CH_3CH_2OH + O_2 \xrightarrow{Cu/\Delta} 2CH_3CHO + 2H_2O$$

**乙醛银镜反应：**
$$CH_3CHO + 2Ag(NH_3)_2OH \xrightarrow{\Delta} CH_3COONH_4 + 2Ag\downarrow + 3NH_3 + H_2O$$

**酯化反应：**
$$CH_3COOH + C_2H_5OH \xrightarrow{浓H_2SO_4/\Delta} CH_3COOC_2H_5 + H_2O$$

**易错点：**
- 酯化反应断键位置：酸脱羟基醇脱氢
- 有机方程式用"→"不用"="
- 高分子化合物的单体判断

### 三、无机化学（约 25 分）

#### 1. 元素周期律

**核心规律：**
- 同周期从左到右：原子半径减小，金属性减弱，非金属性增强
- 同族从上到下：原子半径增大，金属性增强，非金属性减弱
- 金属性强弱判断：与水/酸反应剧烈程度、最高价氧化物对应水化物碱性
- 非金属性强弱判断：与氢气化合难易、最高价氧化物对应水化物酸性

#### 2. 重要元素及其化合物

**钠及其化合物：**
- $Na$ 与水反应：$2Na + 2H_2O = 2NaOH + H_2\uparrow$
- $Na_2O_2$ 与水反应：$2Na_2O_2 + 2H_2O = 4NaOH + O_2\uparrow$
- $Na_2O_2$ 与 $CO_2$ 反应：$2Na_2O_2 + 2CO_2 = 2Na_2CO_3 + O_2$
- $NaHCO_3$ 受热分解：$2NaHCO_3 \xrightarrow{\Delta} Na_2CO_3 + H_2O + CO_2\uparrow$

**铝及其化合物：**
- $Al$ 与 $NaOH$ 反应：$2Al + 2NaOH + 2H_2O = 2NaAlO_2 + 3H_2\uparrow$
- $Al(OH)_3$ 两性：既溶于酸又溶于碱
- 明矾净水：$Al^{3+}$ 水解生成 $Al(OH)_3$ 胶体

**铁及其化合物：**
- $Fe^{2+}$ 与 $Fe^{3+}$ 的转化
- $Fe^{3+}$ 检验：加 $KSCN$ 变红
- $Fe^{2+}$ 检验：加 $NaOH$ 生成白色沉淀迅速变灰绿再变红褐

**氯及其化合物：**
- $Cl_2$ 的实验室制备：$MnO_2 + 4HCl(浓) \xrightarrow{\Delta} MnCl_2 + Cl_2\uparrow + 2H_2O$
- $Cl_2$ 与 $NaOH$ 反应：$Cl_2 + 2NaOH = NaCl + NaClO + H_2O$

**硫及其化合物：**
- 浓硫酸的三大特性：吸水性、脱水性、强氧化性
- $SO_2$ 的漂白性（可逆，加热恢复）

**氮及其化合物：**
- 氨的催化氧化：$4NH_3 + 5O_2 \xrightarrow{催化剂/\Delta} 4NO + 6H_2O$
- 硝酸的强氧化性：与金属反应不生成氢气

#### 3. 离子反应

**离子共存判断：**
- 生成沉淀：$Ba^{2+}$ 与 $SO_4^{2-}$、$Ag^+$ 与 $Cl^-$
- 生成气体：$H^+$ 与 $CO_3^{2-}$、$NH_4^+$ 与 $OH^-$（加热）
- 生成弱电解质：$H^+$ 与 $OH^-$、$H^+$ 与 $CH_3COO^-$
- 发生氧化还原：$Fe^{3+}$ 与 $I^-$、$MnO_4^-$ 与 $Fe^{2+}$

**离子检验：**
- $SO_4^{2-}$：先加稀盐酸，再加 $BaCl_2$
- $Cl^-$：先加稀硝酸，再加 $AgNO_3$
- $CO_3^{2-}$：加稀盐酸，将气体通入澄清石灰水

### 四、化学实验（约 15 分）

#### 常见气体制备

| 气体 | 制备原理 | 收集方法 | 干燥剂 |
|------|---------|---------|--------|
| $H_2$ | $Zn + H_2SO_4(稀)$ | 排水/向下排空气 | 浓$H_2SO_4$ |
| $O_2$ | $2H_2O_2 \xrightarrow{MnO_2}$ | 排水/向上排空气 | 浓$H_2SO_4$ |
| $CO_2$ | $CaCO_3 + HCl(稀)$ | 向上排空气 | 浓$H_2SO_4$ |
| $Cl_2$ | $MnO_2 + HCl(浓)$ | 向上排空气 | 浓$H_2SO_4$ |
| $NH_3$ | $NH_4Cl + Ca(OH)_2$ | 向下排空气 | 碱石灰 |
| $SO_2$ | $Na_2SO_3 + H_2SO_4(浓)$ | 向上排空气 | 浓$H_2SO_4$ |

#### 实验题答题模板

**检验/鉴别类：**
1. 取样
2. 加入试剂（具体名称和用量）
3. 描述现象（颜色变化、沉淀、气泡等）
4. 得出结论

**定量实验类：**
1. 实验目的
2. 实验原理
3. 实验步骤
4. 数据处理
5. 误差分析

**实验方案设计类：**
1. 明确实验目的
2. 选择药品和仪器
3. 设计实验步骤
4. 预期实验现象
5. 注意事项

#### 常见实验操作规范

- **蒸馏：** 温度计水银球在支管口处
- **蒸发：** 有大量晶体析出时停止加热（余热蒸干）
- **过滤：** 一贴二低三靠
- **萃取：** 萃取剂与原溶剂不互溶，溶质在萃取剂中溶解度更大
- **滴定：** 锥形瓶不润洗，滴定管要润洗

## ⚠️ 高频易错点清单

### 化学用语
- [ ] 化学方程式配平错误
- [ ] 离子方程式拆分规则（强酸强碱可溶盐拆，其余不拆）
- [ ] 电子式书写（离子化合物有方括号和电荷，共价化合物没有）

### 化学计算
- [ ] 物质的量浓度计算中体积单位（L）
- [ ] 气体摩尔体积使用条件（标准状况下，气体）
- [ ] 混合气体平均摩尔质量计算

### 实验操作
- [ ] 量筒不能加热、不能作反应容器
- [ ] 容量瓶只能配制特定体积的溶液
- [ ] 蒸馏时冷凝水进出方向（下进上出）

### 有机化学
- [ ] 同分异构体的书写要系统化，避免遗漏
- [ ] 高聚物的单体判断方法
- [ ] 有机反应条件的准确书写

## 📝 常见化学方程式速查

### 高频考查方程式

**工业制备：**
- 硬脂酸甘油酯皂化：$(C_{17}H_{35}COO)_3C_3H_5 + 3NaOH \xrightarrow{\Delta} 3C_{17}H_{35}COONa + C_3H_5(OH)_3$
- 工业制漂白粉：$2Cl_2 + 2Ca(OH)_2 = Ca(ClO)_2 + CaCl_2 + 2H_2O$
- 高炉炼铁：$Fe_2O_3 + 3CO \xrightarrow{高温} 2Fe + 3CO_2$

**离子方程式书写要点：**
- 看反应物和产物的状态
- 强电解质拆，弱电解质不拆
- 检查电荷守恒和原子守恒
