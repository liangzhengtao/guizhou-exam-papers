## 📋 核心考点总结

### 一、函数（约 15 分）

#### 考点内容
- 函数的概念、定义域、值域
- 函数的单调性、奇偶性、周期性
- 指数函数、对数函数、幂函数
- 函数图像与变换

#### 解题模板

**求定义域：**
1. 分母 ≠ 0
2. 偶次根号下 ≥ 0
3. 对数真数 > 0，底数 > 0 且 ≠ 1
4. 取交集

**判断单调性：**
1. 设 $x_1 < x_2$
2. 计算 $f(x_1) - f(x_2)$ 或 $\frac{f(x_1)}{f(x_2)}$
3. 判断正负，得出结论

**判断奇偶性：**
1. 先看定义域是否关于原点对称
2. 计算 $f(-x)$
3. $f(-x) = f(x)$ → 偶函数；$f(-x) = -f(x)$ → 奇函数

#### 常考技巧
- 指数式与对数式互化：$a^b = N \Leftrightarrow b = \log_a N$
- 对数运算律：$\log_a(MN) = \log_a M + \log_a N$
- 函数零点问题：转化为两个函数图像交点

---

### 二、导数（约 15 分）

#### 考点内容
- 导数的几何意义（切线方程）
- 导数与函数单调性
- 导数与极值、最值
- 导数证明不等式

#### 解题模板

**求切线方程：**
1. 求导 $f'(x)$
2. 切点横坐标代入求斜率 $k = f'(x_0)$
3. 点斜式：$y - f(x_0) = f'(x_0)(x - x_0)$

**求单调区间：**
1. 求 $f'(x)$
2. 令 $f'(x) > 0$，解得增区间
3. 令 $f'(x) < 0$，解得减区间

**求极值：**
1. 求 $f'(x) = 0$ 的根
2. 判断根左右 $f'(x)$ 的正负变化
3. 正→负：极大值；负→正：极小值

**导数证明不等式：**
1. 构造辅助函数 $g(x) = f(x) - h(x)$
2. 求 $g'(x)$，判断单调性
3. 求 $g(x)$ 的最小值 ≥ 0（或最大值 ≤ 0）

#### 常考技巧
- 含参讨论：分类讨论参数的取值范围
- 隐零点：设 $f'(x_0) = 0$，用 $x_0$ 表示其他量
- 放缩法：$e^x \geq x+1$，$\ln x \leq x-1$

### 三、三角函数（约 15 分）

#### 考点内容
- 三角函数的图像与性质
- 三角恒等变换
- 正弦定理、余弦定理
- 解三角形

#### 解题模板

**三角函数 $y = A\sin(\omega x + \varphi) + B$ 分析：**
1. $A$ = 振幅，$T = \frac{2\pi}{\omega}$
2. $\varphi$ 由特殊点确定
3. $B$ 由上下平移确定

**解三角形（正弦定理）：**
$$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$$

**解三角形（余弦定理）：**
$$c^2 = a^2 + b^2 - 2ab\cos C$$

**三角恒等变换常用公式：**
- $\sin(A \pm B) = \sin A\cos B \pm \cos A\sin B$
- $\cos(A \pm B) = \cos A\cos B \mp \sin A\sin B$
- $\sin 2\alpha = 2\sin\alpha\cos\alpha$
- $\cos 2\alpha = \cos^2\alpha - \sin^2\alpha = 2\cos^2\alpha - 1 = 1 - 2\sin^2\alpha$

#### 常考技巧
- 辅助角公式：$a\sin x + b\cos x = \sqrt{a^2+b^2}\sin(x+\varphi)$
- 角的变换：$\alpha = (\alpha+\beta) - \beta$
- 解三角形面积：$S = \frac{1}{2}ab\sin C$

### 四、数列（约 12 分）

#### 考点内容
- 等差数列与等比数列
- 数列求和
- 数列通项公式求解
- 数列与不等式

#### 解题模板

**等差数列核心公式：**
- 通项：$a_n = a_1 + (n-1)d$
- 求和：$S_n = \frac{n(a_1 + a_n)}{2} = na_1 + \frac{n(n-1)}{2}d$
- 性质：$a_m + a_n = a_p + a_q$（$m+n=p+q$）

**等比数列核心公式：**
- 通项：$a_n = a_1 \cdot q^{n-1}$
- 求和：$S_n = \frac{a_1(1-q^n)}{1-q}$（$q \neq 1$）

**求通项公式方法：**
1. **累加法：** $a_{n+1} - a_n = f(n)$ → 累加
2. **累乘法：** $\frac{a_{n+1}}{a_n} = f(n)$ → 累乘
3. **构造法：** $a_{n+1} = pa_n + q$ → 构造等比数列
4. **$S_n$ 与 $a_n$ 关系：** $a_n = S_n - S_{n-1}$（$n \geq 2$）

**常见求和方法：**
- 裂项相消法
- 错位相减法（等差×等比）
- 分组求和法

### 五、立体几何（约 12 分）

#### 考点内容
- 空间几何体的表面积和体积
- 线面关系判定
- 空间向量法求角和距离

#### 解题模板

**证明平行：**
- 线面平行：线∥面内一条线 → 线∥面
- 面面平行：一个面内两条相交线分别平行于另一个面 → 面∥面

**证明垂直：**
- 线面垂直：线⊥面内两条相交线 → 线⊥面
- 面面垂直：一个面过另一个面的一条垂线 → 面⊥面

**空间向量法求二面角：**
1. 建立空间直角坐标系
2. 求两个平面的法向量 $\vec{n_1}$，$\vec{n_2}$
3. $\cos\theta = \frac{|\vec{n_1} \cdot \vec{n_2}|}{|\vec{n_1}||\vec{n_2}|}$

**空间向量法求线面角：**
1. 求直线方向向量 $\vec{l}$ 和平面法向量 $\vec{n}$
2. $\sin\theta = \frac{|\vec{l} \cdot \vec{n}|}{|\vec{l}||\vec{n}|}$

### 六、解析几何（约 17 分）

#### 考点内容
- 直线与圆
- 椭圆、双曲线、抛物线
- 直线与圆锥曲线的位置关系
- 定点、定值、最值问题

#### 解题模板

**直线与圆锥曲线联立：**
1. 设直线方程 $y = kx + m$（注意讨论斜率不存在）
2. 与曲线方程联立消元
3. 利用韦达定理：$x_1 + x_2$，$x_1 x_2$
4. 代入条件（中点、弦长、面积等）

**弦长公式：**
$$|AB| = \sqrt{1+k^2} \cdot |x_1 - x_2| = \sqrt{1+k^2} \cdot \sqrt{(x_1+x_2)^2 - 4x_1x_2}$$

**常见曲线标准方程：**
- 椭圆：$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$（$a > b > 0$），$c^2 = a^2 - b^2$
- 双曲线：$\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$，$c^2 = a^2 + b^2$
- 抛物线：$y^2 = 2px$（$p > 0$）

#### 常考技巧
- 设而不求：利用韦达定理，不需要求出具体交点坐标
- 参数方程化普通方程
- 面积问题用叉乘公式：$S = \frac{1}{2}|x_1 y_2 - x_2 y_1|$

### 七、概率统计（约 12 分）

#### 考点内容
- 古典概型与几何概型
- 条件概率与独立事件
- 离散型随机变量的分布列
- 二项分布与正态分布
- 统计图表分析

#### 解题模板

**分布列求解：**
1. 确定随机变量 $X$ 的所有取值
2. 分别计算每个取值的概率 $P(X = x_i)$
3. 验证：$\sum P(X = x_i) = 1$
4. 求期望：$E(X) = \sum x_i P(X = x_i)$
5. 求方差：$D(X) = E(X^2) - [E(X)]^2$

**二项分布 $X \sim B(n, p)$：**
- $P(X=k) = C_n^k p^k (1-p)^{n-k}$
- $E(X) = np$
- $D(X) = np(1-p)$

**正态分布 $X \sim N(\mu, \sigma^2)$：**
- $\mu$ 决定对称轴位置
- $\sigma$ 决定曲线"胖瘦"
- $P(\mu - \sigma < X < \mu + \sigma) \approx 68.3\%$
- $P(\mu - 2\sigma < X < \mu + 2\sigma) \approx 95.4\%$

## 🎯 选择题技巧

### 1. 直接法
直接计算或推理得出答案。适用于概念清晰、计算简单的题目。

### 2. 特值法
选取特殊值代入验证。适用于含参数的不等式、恒成立问题。

**示例：** $a > b > 0$，比较大小 → 设 $a=2, b=1$ 代入

### 3. 排除法
根据已知条件排除明显错误的选项。适用于图像选择题。

### 4. 数形结合
画出函数图像或几何图形，直观判断答案。适用于函数、不等式、解析几何题。

### 5. 极端化
将变量取极端值，快速判断趋势。适用于动态变化问题。

### 6. 估算法
大致估算结果范围，选择唯一符合的选项。适用于计算量大的题目。

## ⚠️ 高频易错点清单

### 函数与导数
- [ ] 定义域优先原则（求任何函数问题先看定义域）
- [ ] 导数为零的点不一定是极值点（还需左右变号）
- [ ] 复合函数求导链式法则遗漏内层导数

### 三角函数
- [ ] 辅助角公式中 $\varphi$ 的确定
- [ ] 解三角形中"角化边"还是"边化角"的选择
- [ ] 已知两边和一边对角时的多解问题

### 数列
- [ ] $a_n$ 与 $S_n$ 关系中 $n=1$ 要单独验证
- [ ] 等比数列公比 $q=1$ 的特殊情况
- [ ] 错位相减法中错位后系数符号

### 立体几何
- [ ] 建系时三条棱必须两两垂直
- [ ] 法向量求解时选取的向量必须在平面内
- [ ] 二面角的范围是 $[0, \pi]$

### 解析几何
- [ ] 讨论直线斜率不存在的情况
- [ ] 韦达定理前提：判别式 $\Delta > 0$
- [ ] 椭圆与双曲线中 $a, b, c$ 的关系不同

### 概率统计
- [ ] 互斥事件和对立事件的区别
- [ ] 独立重复试验的条件
- [ ] 期望和方差的计算公式
